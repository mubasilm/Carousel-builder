# Carousel Patterns

Use these patterns to choose the slide structure quickly.

## Slide Count Heuristics

### 4 slides

Use for:
- contrarian takes
- engineering credibility pieces
- one named insight
- one prediction

Pattern:
1. thesis
2. proof or problem
3. explanation or model
4. buyer action / takeaway

### 5 slides

Use for:
- named patterns
- richer thought leadership
- one thesis with two supporting developments

Pattern:
1. thesis
2. pattern or history
3. current shift
4. implication
5. action / close

### 6-8 slides

Use for:
- long essays
- research projects
- PDF-to-carousel adaptation
- when the user wants the copy to stay close to an existing source

Pattern:
1. hook
2. frame
3. proof 1
4. proof 2
5. implication
6. future / contrast
7. action
8. close

## Visual Archetypes

Choose one primary visual system:

- **Editorial memo**: strong type, minimal graphics, premium whitespace
- **Structured diagram**: loops, ladders, dependency maps, system flows
- **Comparison brief**: two-column contrasts, matrices, wedges
- **Signal / architecture piece**: nodes, orchestration, layered systems, context maps

## CTA Pair Pattern

Use value on the left, action on the right.

Examples:
- `This is the short version. The full blog is in the first comment.` / `Read full blog`
- `If you want the full argument, it’s in the first comment.` / `Read full post`
- `I unpack the full framework in the blog.` / `Read the framework`

Avoid:
- `Read the full blog in the first comment...` + `Link in comments`

That repeats the same meaning twice.

## Figma Make Checklist

Every prompt should include:
- exact dimensions
- audience
- tone
- visual direction
- slide-by-slide copy
- visual notes per slide
- brand constraints
- final quality bar
